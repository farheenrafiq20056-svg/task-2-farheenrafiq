# 🌸 Data Classification Using AI — Iris Flower Classifier

A supervised machine learning project that trains a KNN classification
model to identify Iris flower species from measurements.
Built as Project 2 of my AI Engineering journey at DecodeLabs Batch 2026.

---

## 📌 Project Overview

This project demonstrates the complete Machine Learning pipeline —
from loading raw data to making intelligent predictions using the
K-Nearest Neighbors (KNN) algorithm on the classic Iris dataset.

---

## 🎯 Goal

Build a basic classification model using a small dataset that can
predict the species of an Iris flower based on its measurements.

---

## ✅ Key Requirements Completed

- ✔️ Loaded and explored the Iris dataset
- ✔️ Split data into 80% training and 20% testing sets
- ✔️ Applied KNN classification algorithm
- ✔️ Achieved 100% model accuracy
- ✔️ Generated full classification report with F1 scores
- ✔️ Predicted species of a new unseen flower

## 📊 About the Dataset

| Property | Value |
|---|---|
| Dataset | Iris Benchmark Dataset |
| Total Samples | 150 flowers |
| Classes | 3 (Setosa, Versicolor, Virginica) |
| Features | 4 (Sepal Length, Sepal Width, Petal Length, Petal Width) |
| Split | 80% Train / 20% Test |
